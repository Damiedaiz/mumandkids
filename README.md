# Mum & Kids Outfits

Independent commerce storefront migrated from DaizLab. Built with the MOYO engineering standard: mobile-first editorial commerce, reusable components, accessible interactions, structured metadata, and a clear separation between storefront and commerce integrations.

## Development

- `npm install`
- `npm run dev`

Configure the environment variables documented in `.env.example` before connecting the Supabase catalogue and merchant operations.
